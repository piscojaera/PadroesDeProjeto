# Padrões de Projeto

Repositório criado para a atividade prática da matéria de Padrões de Projeto, utilizando Java.

## Questão 1 - Observer
Sistema de monitoramento de estoque que avisa os setores de Compras, Vendas e Auditoria quando a quantidade de um produto é alterada.

## Questão 2 - Strategy
Sistema de cobrança de estacionamento com três tipos de tarifas: Rotativo, Mensalista e Conveniado.

## Questão 3 - Decorator
Sistema de pedidos de café que permite adicionar complementos às bebidas e atualizar automaticamente o preço e a descrição do pedido.

## Tecnologias
- Java
- Git
- GitHub
